# NeuroLab — учебная лаборатория по теории ИИ

NeuroLab — настольное приложение для изучения свёрточных нейронных сетей на задаче классификации одежды из Fashion-MNIST. Проект объединяет обучение модели на PyTorch, просмотр данных, визуализацию архитектуры, оценку ошибок и эксперименты с изменением входных изображений.

Приложение позволяет проследить путь от изображения до предсказания и сопоставить теоретические понятия — свёртку, активацию, pooling, функцию потерь, градиентное обучение и обобщение — с работающей реализацией. Интерфейс использует английские названия разделов и русские пояснения.

## Возможности

| Раздел | Назначение |
| --- | --- |
| **Dashboard** | Общие сведения о модели, числе параметров, устройстве и классах |
| **Dataset** | Загрузка Fashion-MNIST и постраничный просмотр обучающих изображений с метками |
| **Architecture** | Схема CNN с размерами тензоров и пояснениями типов слоёв |
| **Training** | Обучение, настройка эпох, размера батча и learning rate; пауза, остановка и сброс весов |
| **Feature Maps** | Раздел для просмотра промежуточных активаций; текущая реализация требует исправления, см. ограничения |
| **Prediction** | Классификация своего изображения, наиболее вероятный класс и top-5 вероятностей |
| **Confusion Matrix** | Вычисление матрицы ошибок на валидационной выборке |
| **What If?** | Сравнение предсказаний для исходного изображения и шести преобразований |
| **Settings** | Информация о CPU, памяти, GPU и доступности CUDA |

## Технологии

- **Python** — язык реализации. Для нового окружения можно использовать Python 3.12: эта версия указана в локальном окружении проекта; отдельного ограничения версии в репозитории нет.
- **PyTorch и torchvision** — CNN, обучение, загрузка и подготовка Fashion-MNIST.
- **PySide6** — графический интерфейс; обучение выполняется в `QThread`.
- **pyqtgraph** — графики loss/accuracy и матрица ошибок.
- **NumPy и Pillow** — обработка изображений.
- **py-cpuinfo и psutil** — сведения об оборудовании.

Минимальные версии библиотек перечислены в [requirements.txt](NeuroLab/requirements.txt). Точные версии не зафиксированы lock-файлом.

## Установка и запуск

Команды ниже выполняются из корня репозитория `Project_AI`, где находится этот README. Нужны установленный Python и графическая среда. NVIDIA GPU не требуется: в текущем коде устройство явно задано как `cpu`.

### Windows / PowerShell

```powershell
cd NeuroLab
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app/main.py
```

Активация окружения не обязательна: команды напрямую используют его интерпретатор. Если используется другая установленная версия Python, замените `py -3.12` соответствующей командой.

### Linux / macOS

```bash
cd NeuroLab
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python app/main.py
```

Эти команды соответствуют структуре проекта; работа GUI на Linux и macOS отдельно не проверена. Точка входа — `NeuroLab/app/main.py`. В PyCharm выберите интерпретатор окружения, в котором установлены зависимости, и запустите этот файл.

При отсутствии локального датасета приложение скачивает Fashion-MNIST через torchvision: для этого нужен интернет. В текущем репозитории уже присутствуют исходные файлы обучающей и тестовой выборок в `assets/data/FashionMNIST/raw/`.

## Сценарий демонстрации

1. Откройте **Dataset** и нажмите **Load / Download Fashion-MNIST**, чтобы посмотреть изображения и метки.
2. Изучите **Architecture**: как меняются число каналов и пространственное разрешение после каждого слоя.
3. В **Training** выберите **Quick Demo** и нажмите **Start Training**. Сравните train/validation loss и accuracy по эпохам.
4. Дождитесь завершения обучения. Веса общей модели будут доступны разделам предсказания и анализа в этой сессии.
5. В **Prediction** загрузите изображение одежды. Оно автоматически переводится в оттенки серого и масштабируется до 28×28. Для содержательного результата используйте изображение, похожее на Fashion-MNIST: светлый предмет на тёмном фоне.
6. В **What If?** нажмите **Random Sample** или загрузите своё изображение и сравните предсказания для всех преобразований.
7. После окончания обучения вычислите **Confusion Matrix** и рассмотрите, какие классы модель путает.

До обучения модель имеет случайные веса, поэтому её предсказания не отражают выученные признаки. Кнопка **Demo** в Prediction генерирует случайный шум и служит для демонстрации вывода, а не проверки качества классификации.

## Данные и подготовка

Fashion-MNIST содержит 70 000 изображений размером **28×28**, по одному каналу: **60 000** обучающих и **10 000** тестовых. Эти размеры подтверждаются заголовками локальных IDX-файлов.

Классы в порядке выходов модели:

| Индекс | Название | Значение |
| --- | --- | --- |
| 0 | T-shirt/top | Футболка / топ |
| 1 | Trouser | Брюки |
| 2 | Pullover | Пуловер |
| 3 | Dress | Платье |
| 4 | Coat | Пальто |
| 5 | Sandal | Сандалии |
| 6 | Shirt | Рубашка |
| 7 | Sneaker | Кроссовки |
| 8 | Bag | Сумка |
| 9 | Ankle boot | Ботильоны |

`ToTensor()` переводит значения пикселей в диапазон `[0, 1]`, затем `Normalize((0.5,), (0.5,))` преобразует их в `[-1, 1]`. При обработке загруженных изображений применяется та же нормализация.

Для обучения 10% выбранной обучающей части отводится под валидацию. Разбиение использует `torch.Generator().manual_seed(42)`. Подмножества для сокращённых режимов состоят из первых N элементов исходного датасета. Обучающий загрузчик перемешивает данные и отбрасывает неполный последний батч (`drop_last=True`); `num_workers=0`.

| Режим | Обучение | Валидация | Подготовленная тестовая часть | Эпохи по умолчанию | Batch size |
| --- | ---: | ---: | ---: | ---: | ---: |
| Quick Demo | 4 500 | 500 | 1 000 | 3 | 64 |
| Normal | 18 000 | 2 000 | 5 000 | 5 | 128 |
| Full | 54 000 | 6 000 | 10 000 | 10 | 128 |

Эпохи и batch size можно изменить. Learning rate по умолчанию — **0.001**. В процессе обучения тестовый загрузчик создаётся, но не используется для расчёта метрик.

Отдельный раздел **Confusion Matrix** всегда формирует валидационную выборку из полной обучающей части — 6 000 изображений. Она отличается от валидации Quick Demo и Normal и может включать изображения, использованные для обучения в этих режимах; её нельзя считать независимой оценкой на тестовой выборке. Матрица на странице Training использует валидационный загрузчик текущего режима.

## Архитектура и обучение

Модель `SmallCNN` содержит **206 922 обучаемых параметра**. Размеры ниже указаны без измерения батча.

| Этап | Операция | Размер выхода |
| --- | --- | --- |
| Вход | Grayscale-изображение | 1×28×28 |
| Блок 1 | Conv2d(1 → 16, kernel=3, padding=1), ReLU | 16×28×28 |
| Pooling 1 | MaxPool2d(2) | 16×14×14 |
| Блок 2 | Conv2d(16 → 32, kernel=3, padding=1), ReLU | 32×14×14 |
| Pooling 2 | MaxPool2d(2) | 32×7×7 |
| Flatten | Разворачивание тензора | 1 568 |
| Классификатор | Linear(1568 → 128), ReLU | 128 |
| Выход | Linear(128 → 10) | 10 логитов |

Используются **Adam** и **CrossEntropyLoss**. Softmax применяется при предсказании для получения вероятностей; в обучении функция потерь получает логиты. Accuracy отображается в процентах. Цвет матрицы ошибок нормализован по истинному классу, а числа в ячейках показывают абсолютное количество примеров.

Фиксирован seed разбиения выборки, но не всей процедуры обучения: инициализация весов, перемешивание батчей и случайные преобразования могут менять результаты. Подтверждённых значений итоговой точности или времени обучения в репозитории нет.

### Эксперименты What If?

Одновременно показываются исходное изображение и варианты: Gaussian Blur с радиусом 2, Gaussian Noise со стандартным отклонением 30, поворот на 15°, инверсия, увеличение яркости в 1.5 раза и контраста в 1.5 раза. Преобразования применяются к оригиналу независимо друг от друга. Кнопки преобразований пересчитывают весь набор вариантов; сила воздействия не настраивается.

## Сохранение модели

После завершения или штатной остановки обучения веса сохраняются в:

```text
NeuroLab/assets/models/neurolab_cnn.pth
```

Файл перезаписывается при следующем сохранении. Checkpoint содержит словарь с ключом `model_state_dict`; состояние оптимизатора, история метрик и номер эпохи не сохраняются. В репозитории уже есть файл весов, но его качество и происхождение не подтверждены.

**При запуске checkpoint автоматически не загружается**, и кнопки загрузки весов в интерфейсе нет. После перезапуска потребуется новое обучение либо самостоятельное добавление загрузки checkpoint в код. Повторный Start Training продолжает обучение текущих весов с новым оптимизатором и новой историей; **Reset Model** создаёт модель со случайными весами.

## Текущее состояние и ограничения

- **Feature Maps требует исправления:** hooks возвращают четырёхмерные тензоры активаций, а `_render_maps()` ожидает двумерные массивы изображений. Функция `activation_to_grid()` уже реализована в `visualization/feature_maps.py`, но страница её не вызывает. Сейчас отображение карт завершается ошибкой.
- **Вычисления выполняются на CPU.** Settings показывает доступность CUDA в системе, но не переключает устройство приложения.
- **Не запускайте анализ модели во время обучения.** Страницы используют общую модель, а вычисления матрицы ошибок и предсказаний вызывают `eval()`; синхронизации с обучающим потоком нет.
- **Загрузка данных и отдельный расчёт матрицы ошибок выполняются в GUI-потоке**, поэтому интерфейс может временно перестать отвечать. Quick Demo сокращает обучение, но первоначальная загрузка всё равно подготавливает полный датасет.
- **Произвольные фотографии могут сильно отличаться от Fashion-MNIST.** Приложение изменяет размер и нормализует изображение, но не выделяет предмет, не удаляет фон и не определяет неизвестные классы. Процент softmax не является гарантией правильного ответа.
- Автоматизированные тесты, lock-файл зависимостей и отдельный файл лицензии в репозитории отсутствуют.
